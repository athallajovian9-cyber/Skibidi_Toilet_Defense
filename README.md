# 🚽 Skibidi Toilet Defense: Sigma Edition 🪠

Official web repository and GitHub Pages source for **Skibidi Toilet Defense: Sigma Edition**.

- 🎮 **Play Online:** Host this repository with GitHub Pages to play directly from any browser or mobile device.
- 🚀 **Desktop Mode:** Run `launcher.bat` on Windows for frameless fullscreen app mode with auto-browser detection.

## Godot port

The playable Godot 4 vertical slice lives in [`godot/`](godot/). It is a
separate project so the existing website remains unchanged. See
[`godot/README.md`](godot/README.md) for setup, controls, and Windows/Android/iOS
export notes.
